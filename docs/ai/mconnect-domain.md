# M-Connect Domain Knowledge

M-Connect is an enterprise integration middleware.

Main concepts:

- Integration
- Mapping Profile
- Lookup Table
- Execution
- Pipeline
- Trace ID

An Integration connects an external system to M-Connect.

A Mapping Profile transforms external data into the canonical format.

A Lookup Table maps values from one system to another.

An Execution represents a message moving through the pipeline.

A Trace ID uniquely identifies a processed message.

Users monitor integrations through dashboards and execution logs.
